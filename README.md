# MailChat

פלטפורמת תקשורת בזמן אמת המבוססת על כתובת המייל — שיחות פרטיות וקבוצות.

## הפעלה

```bash
npm install
npm run dev
```

פתחו את הכתובת שמופיעה בטרמינל (בדרך כלל http://localhost:5173).

## יכולות

- התחברות / הרשמה עם מייל וסיסמה, או קישור קסם
- מסך מפוצל: סרגל שיחות + חלון צ׳אט
- שיחות פרטיות לפי מייל וקבוצות לפי נושא
- שמירה מקומית בדפדפן (LocalStorage)
